# Ticho

Home of everything for DJ Ticho.

| Folder | What |
|---|---|
| [`website/`](website/) | Public site (Gigs · Music · About) + back-office at `/admin/`. Vite + React + Firebase. |
| [`promotional-content/`](promotional-content/) | Promo material, mostly video (Blender etc.). |

**Live site:** https://dovskyrick.github.io/ticho/
**Back-office:** https://dovskyrick.github.io/ticho/admin/

Deploys automatically via GitHub Actions on every push that touches `website/`.
Firebase setup checklist: [`website/docs/HIL-firebase-setup.md`](website/docs/HIL-firebase-setup.md).
